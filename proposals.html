中身は自分で。
スライドの構成は自動で。

中身(本文)はあなたが書く前提で、ローカルの Dify ワークフロー (Claude Sonnet) が スライドの構成・レイアウトの枠だけを設計します。資料全体の構成、または「こんなスライドを作りたい」 から1枚の構成案を。生成は手元の Dify 経由なので、キーは外に出ません。

セットアップが必要です

Dify 接続設定が見つかりません

  1. Dify を起動: cd ~/dify/docker && docker compose up -d
  2. Anthropic キーを Dify に登録: python3 ~/dify/automation/dify.py add-provider langgenius/anthropic/anthropic '{"anthropic_api_key":"sk-ant-…"}'
  3. ワークフローを取り込み: python3 ~/dify/automation/dify.py import flows/proposal-skeleton.yml → 表示された app_id で … key <app_id> を実行し app キーを取得
  4. config.example.json を config.local.json にコピーし、difyAppKey を貼る
  5. このページを再読み込み

構成

左のフォームを入力して「構成を生成」を押してください。
